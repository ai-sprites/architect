# 接口设计

让提供方和消费方对同一行为形成可检查的约定。本实践可独立使用，既适用于 HTTP，也适用于项目已有的 RPC、事件或内部接口；不会要求改成 REST、统一响应包装或 OpenAPI。

- 新增或细化接口：读 [契约内容](references/contracts.md)。
- 修改已有接口、分页或分批发布：读 [兼容与演进](references/compatibility.md)。

先找现有契约来源、调用者和已确认行为，按实际协议补充受影响部分。用真实例子或现有契约检查确认理解，不能把工具支持的格式当成业务要求。未知语义列“待确定”并说明依赖；交付可用约定及检查结果，文档按需要保存。
