# 技术决定

把当前架构问题整理为有证据、能执行的选择。此实践可独立使用，不要求安装 Architect 或补齐技术档案；已有项目约定和用户选择优先，安装本实践不会产生新的技术规范。

- 技术选型、迁移或难以撤回的决定：读 [决定与取舍](references/decisions.md)。
- 系统关系、部署边界、质量约束或风险分析：读 [边界与验证](references/boundaries.md)。

先确定这次需要改变什么，再读取相关代码、配置和已有决定。产出结论、证据、成本及验证方式，详略随任务；仅在要长期引用时保存文档。未解决项列“待确定”，保留来源和受影响部分，不能用推荐方案替代用户尚未作出的决定。
